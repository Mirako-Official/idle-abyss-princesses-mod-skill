# iap-hero-mod

Claude Code plugin with one skill, `iap-hero-mod`: make a complete custom hero mod for the Steam game
Idle Abyss Princesses (深渊放置姬) — design, portrait and expressions, chibi battle sprites, 16×16 icons,
hero.js, translations, hero-lab balance, optional AI chat (IAP.ai) and the Steam Workshop upload.
Game 3.1.1+: transforming heroes (a dragon-form style timed form with its own sprite) and dashes.
The player chooses the image model (own art, OpenAI-compatible API, NovelAI or local Stable Diffusion).

Needs the desktop game (Settings → Mods → Author Tools → Author Kit, once) and Python 3 with
`pip install pillow numpy`. See the repository README for installation and usage.

Install:

```
/plugin install iap-hero-mod --marketplace Mirako-Official/idle-abyss-princesses-mod-skill
```
